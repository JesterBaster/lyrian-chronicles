The Lyrian Chronicles

An unofficial Foundry VTT game system for Angel’s Sword Studios’ tabletop RPG.

Foundry v13–v14 Unofficial Work in progress

Install

In Foundry: Game Systems → Install System, then paste this manifest URL.

https://github.com/JesterBaster/lyrian-chronicles/releases/latest/download/system.json

What it handles

RuleBehaviour
Derived statsHP 20 + Toughness×10, Mana 6 + Power, RP 2 + Agility, Evasion 7 + Agility, Potency 11 + Focus
AttacksLight 2d4 + Power, Heavy 4d6 + 2×Power (5d6 two-handed melee), Precise at doubled Focus with Pinpoint
CriticalsNatural 20, or 19 with Keen weapon groups: maximum damage plus Half Pierce
DefenceChat card buttons for Dodge and Block; Block uses 2×Toughness + armour block value and can reduce damage to zero
Initiative1d4 + Agility, ties resolved for players and bosses first, then heroics, then grunts
Action economy4 AP and 2 + Agility RP for heroics, 2 AP and 1 RP for grunts
Once per roundNon-Rapid abilities lock until your next turn; one Secret Art per encounter
Injuries1d10 table roll creates an Injury item on the actor

Left to the table

Cover, stealth, grapple escape power, mounted combat, crafting dice pools, gathering node points and interlude bookkeeping have fields on the sheet but are resolved by the GM. That is deliberate — automating them before the system has seen play tends to lock in the wrong assumptions.

Modules

Generic modules work: Dice So Nice, Drag Ruler, Sequencer, FXMaster, Monk’s Token Bar, Automated Animations. System-specific modules do not — a D&D 5e module reads system.abilities.str and finds nothing here. Every bonus is a real schema field (system.stats.power.bonus, system.defences.guardBonus), so Active Effects and the modules that drive them apply cleanly.
